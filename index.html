INPUT SIGNALS

情報の前に、
相手を理解する。

同じ情報でも、届ける相手・情報そのもの・利用する状況が変われば、最適なかたちは変わります。IAはまず、この3つの信号を拾います。

USER — 誰が使うか
CONTENT — 何を伝えるか
CONTEXT — いつ、どこで使うか
HANDS-ON WORKSHOP

ぐちゃぐちゃな情報を、IAで組み上げる

メモ、資料、画面案をそのまま持ち込み、情報の流れを設計します。

1

素材を全部出す

順番や正しさを気にせず、手元にある情報をカードにします。

お知らせ申請方法料金FAQ対象者締切
2

3つの柱で問い直す

「だれに？」「なにを？」「どんな場面で？」をカードごとに書きます。

USER：初めて申請する人
CONTENT：必要書類と手順
CONTEXT：締切直前、スマホで確認
3

4つの仕組みにする

まとまり、名前、道筋、探し方を決め、ページに反映します。

組織化：「申請する」に集約
ラベル：「はじめての申請」
ナビ：手順を1 → 2 → 3で案内
検索：「必要書類」で探せる
